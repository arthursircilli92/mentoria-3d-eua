# Mentoria 3D EUA — Sala de Controle

Material completo das 4 aulas da mentoria de impressão 3D para o mercado americano, com **Painel de Troca** para definir quem apresenta cada bloco (Arthur ou Guilherme).

## 🚀 Deploy no Vercel

1. Suba esta pasta (`mentoria-site/`) para um repositório no GitHub.
2. No Vercel, importe o repositório.
3. O Vercel detecta automaticamente que é um site estático (HTML/CSS/JS puro).
4. Clique em **Deploy**.

Pronto! O site estará no ar em segundos.

## 🛠️ Como usar

- Abra o `index.html` no navegador.
- Use o **Painel de Troca** no topo para definir quem fala cada bloco.
- As cores, badges e cronograma atualizam na hora.
- As escolhas ficam salvas no navegador (localStorage).
- Para sincronizar entre dois computadores: um clica em "📋 Copiar config", manda no WhatsApp, e o outro clica em "📥 Colar config".

## 📋 Estrutura

- `index.html` — Arquivo único com todo o conteúdo (HTML + CSS + JS embutidos).
- Nenhuma dependência externa (exceto Google Fonts).
